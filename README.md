# System Configuration Comparison Tool

## Overview

The System Configuration Comparison Tool is a Python-based GUI application designed to retrieve and compare computer system configurations.

The application provides a simple graphical interface for viewing important hardware and software information and comparing two system configurations.

## Features

* Retrieve system information
* Display operating system details
* Display CPU information
* Display RAM information
* Display storage information
* Display computer name and architecture
* Save configuration as System A
* Save configuration as System B
* Compare System A and System B
* Highlight identical and different configurations
* Simple and user-friendly GUI

## Technologies Used

* Python
* Tkinter
* Psutil
* GitHub

## System Information Retrieved

The application can retrieve:

* Operating System
* OS Version
* OS Release
* Computer Name
* Processor
* CPU Cores
* CPU Threads
* CPU Frequency
* Total RAM
* Available RAM
* RAM Usage
* Total Storage
* Used Storage
* Free Storage
* Storage Usage
* Last Boot Time
* Python Version

## Installation

### 1. Install Python

Install Python 3.x on your computer.

### 2. Install the required library

Open Command Prompt or Terminal and run:

```bash
pip install psutil
```

### 3. Run the application

Navigate to the project folder and run:

```bash
python system_configuration_comparison.py
```

## How to Use

1. Open the application.
2. Click **Refresh System** to retrieve the current configuration.
3. Click **Save as System A**.
4. Run the application on another computer or use another configuration.
5. Click **Save as System B**.
6. Click **Compare Systems**.
7. The comparison window displays the differences between both systems.

## Project Objective

The objective of this project is to develop a simple tool that can retrieve system configuration information and provide an easy way to compare different computer systems.
